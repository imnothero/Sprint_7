# Sprint_7: Автоматизированные тесты API Яндекс Самокат

## Описание проекта

Проект содержит набор автоматизированных тестов для проверки API учебного сервиса Яндекс Самокат (документация: [qa-scooter.praktikum-services.ru/docs/](https://qa-scooter.praktikum-services.ru/docs/)). Тесты разработаны с использованием Python, библиотеки `pytest`, `requests` и `allure-pytest` для генерации отчётов. 

Цель проекта — проверить корректность работы API, включая создание курьера, авторизацию, создание заказа и получение списка заказов, а также обработку ошибок в соответствии с требованиями API.

## Покрытие тестов

Тесты покрывают следующие ручки API:
- **Создание курьера** (`POST /api/v1/courier`):
  - Успешное создание курьера.
  - Ошибка при создании курьера с существующим логином.
  - Ошибка при отсутствии обязательных полей (`login`, `password`).
  - Успешное создание без необязательного поля `firstName`.
- **Логин курьера** (`POST /api/v1/courier/login`):
  - Успешная авторизация с возвращением `id`.
  - Ошибки при неверном логине/пароле, отсутствии полей или несуществующем пользователе.
- **Создание заказа** (`POST /api/v1/orders`):
  - Создание заказа с одним цветом (`BLACK` или `GREY`), двумя цветами или без цвета.
  - Проверка наличия поля `track` в ответе.
- **Получение списка заказов** (`GET /api/v1/orders`):
  - Проверка, что возвращается список заказов.
